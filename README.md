# Simulation du calcul du revenu cadastral du matériel et outillage en Wallonie

Cet outil n'est pas un service officiel de l'administration belge. Il est développé indépendamment et n'est ni affilié à, ni approuvé par, ni géré par une autorité publique.

## Avertissement

Les résultats fournis par ce site sont des estimations obtenues à partir de règles de calcul établies sur la base de textes de lois et décrets publiquement accessibles.

Les montants calculés sont fournis à titre purement informatif et ne garantissent pas le montant qui sera effectivement réclamé ou appliqué par l'administration compétente.

## Confidentialité et données personnelles

Les données saisies dans le simulateur et les fichiers sélectionnés sont traités localement dans le navigateur de l'utilisateur afin d'effectuer les calculs.

Le site ne conserve pas les résultats des simulations et ne transmet pas volontairement les fichiers sélectionnés à un serveur.

Certaines données techniques peuvent toutefois être traitées par le fournisseur d'hébergement ou les services techniques nécessaires au fonctionnement du site. Pour plus d'informations, veuillez consulter leurs politiques respectives.
